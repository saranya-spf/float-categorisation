# Float Categorisation

This repository contains the implementation for float transaction categorization.

## Getting Started

Follow the steps below to set up and run the project locally:

### 1. Clone the Repository

```bash
git clone https://github.com/saranya-spf/float-categorisation.git
```

### 2. Navigate to the Project directory

```bash
cd float-categorisation
```

### 3. Create and Activate a Virtual Environment
Create a python virtual environment
```bash
cd float-categorisation
```

### 3. Create and Activate a Virtual Environment
Create a python virtual environment
```bash
python -m venv .venv
```

Activate it
```bash
source .venv/bin/activate
```

### 4. Install Dependencies
```bash
pip install -e .
```

### 5. Run the Application
```bash
python -m float_categorization
```
